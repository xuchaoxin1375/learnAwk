## 变量与表达式

awk 的变量不需要声明，第一次赋值就创建。看起来简单，但它有两种基本类型（字符串和数字）以及一种介于两者之间的“数字字符串”，比较和拼接的结果经常和直觉不同。这一篇把类型、运算、比较和变量传递讲清楚。

### 三种值

awk 的值可以分成三类：

- **数字**(number)：`42`、`3.14`、`1e3`。
- **字符串**(string)：`"Alice"`、`"2026-01-05"`。
- **数字字符串**(strnum)：从输入字段、`-v` 参数或 `split()` 结果中得到、内容看起来像数字的值，例如字段 `$4` 是 `120000`。

前两类是字面量类型，第三类是运行时根据上下文产生的。`strnum` 的存在是为了让“从文件读到的数字”既能按数字比较，也能保留原始文本。

```shell
$ printf '010\n' | awk '{ print ($1 == 10), ($1 == "010"), ($1 + 0) }'
1 1 10
```

`$1` 是 `010`，看起来像数字，所以它和数字 `10` 比较时按数值相等；它和字符串 `"010"` 比较时也相等，因为原始文本保留着。`$1 + 0` 强制按数字处理，得到 10。

### 未初始化变量

未初始化变量既是空字符串，也是数字 0：

```shell
$ awk 'BEGIN { print "[" x "]"; print x + 0; print x "" }'
[]
0

```

最后一行是空行，因为 `x ""` 是字符串拼接，结果为空字符串。实际写程序时，依赖未初始化值容易让逻辑含糊，**在 `BEGIN` 里显式初始化**更清楚：

```awk
BEGIN { total = 0; count = 0 }
```

### 算术运算

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `+`、`-`、`*`、`/` | 加、减、乘、除 | `$4 * 0.8` |
| `%` | 取余 | `NR % 2` |
| `^` 或 `**` | 幂 | `2 ^ 10`，`**` 是 GNU 扩展 |
| `+`、`-` 一元 | 正号、负号 | `-x` |

```shell
$ awk 'BEGIN { print 1 / 2; print int(7 / 2); print 2 ^ 10; print 7 % 3 }'
0.5
3
1024
1
```

awk 的 `/` 是浮点除法，`1 / 2` 得到 `0.5`。需要整数除法时用 `int()` 截断，或对正数用 `int(a / b)`。

浮点数有二进制表示误差：

```shell
$ awk 'BEGIN { print 0.1 + 0.2; printf "%.17f\n", 0.1 + 0.2 }'
0.3
0.30000000000000004
```

默认 `print` 用 `OFMT`（通常是 `%.6g`）把数字转成字符串，所以显示 `0.3`；`printf` 指定 17 位小数后能看到实际存储值。涉及金额时，用整数分计算，或在输出时统一 `printf "%.2f"`，不要用浮点数直接比较相等。

### 字符串拼接

awk 没有专门的字符串拼接运算符，两个表达式相邻就是拼接：

```shell
$ awk 'BEGIN { print "3" "4"; print 1 2; print "total=" 10 + 5 }'
34
12
total=15
```

注意优先级：`+` 比相邻拼接先算，所以 `"total=" 10 + 5` 先算 `10 + 5`，再拼接成 `total=15`。不确定时加括号：

```awk
print "total=" (10 + 5)
```

`print $1 $2` 是拼接，`print $1, $2` 是用 `OFS` 分隔。两者输出可能很像，但含义不同。

### 比较与类型

比较规则可以简化为：

- 两个操作数都是数字或 `strnum`：按数值比较。
- 至少一个是普通字符串：按字符串比较，数字会先转成字符串。
- 字符串比较受 locale 的排序规则影响，确定性脚本里常用 `LC_ALL=C`。

```shell
$ awk 'BEGIN { print ("10" > 9), (10 > 9), ("10" > "9") }'
0 1 0
```

`"10"` 是普通字符串，和数字 `9` 比较时按字符串规则，`"10"` 的第一个字符 `1` 小于 `9`，所以为假。`10 > 9` 是数字比较，为真。`"10" > "9"` 是字符串比较，也为假。

从输入读到的字段通常是 `strnum`，所以 `$4 > 100000` 能按数值工作：

```shell
$ printf '10\n9\n' | awk '{ print $1, ($1 > 9) }'
10 1
9 0
```

但表头是普通字符串，`$4` 是 `salary`，和数字比较时会走字符串规则，可能意外为真。这就是为什么筛选前要加 `NR > 1`。

需要强制数字比较时，加 `+0`：

```awk
$4 + 0 > 100000
```

需要强制字符串比较时，拼接空字符串：

```awk
$4 "" == "120000"
```

### 赋值与自增

```shell
$ awk 'BEGIN {
  x = 5
  x += 3; print x
  print x++
  print x
  print ++x
}'
8
8
9
10
```

`x++` 返回旧值再自增，`++x` 先自增再返回值。`--` 同理。awk 也支持 `+=`、`-=`、`*=`、`/=`、`%=`、`^=`。

赋值是表达式，可以连续写：

```awk
a = b = 3
```

但为了可读性，分开写更好。

### 三元表达式

```shell
$ awk 'BEGIN { score = 85; print (score >= 60 ? "pass" : "fail") }'
pass
```

三元表达式适合短小的二选一。如果分支里有多个语句，用 `if` 更清楚。

### 变量与字段

变量名区分大小写。`$` 后面跟数字或变量表示字段：

```shell
$ awk -F '\t' 'NR == 2 { i = 3; print $i, $(i + 1) }' examples/data/employees.tsv
Engineering 120000
```

`$i` 是“第 i 个字段”，不是变量 `i` 的值本身。`$(i + 1)` 的括号不能省，否则 `$i + 1` 会被解释成“第 i 个字段加 1”。

`NF` 是字段数，`NR` 是记录号，`FNR` 是当前文件记录号。它们都是普通变量，可以读，也可以赋值，但给 `NF` 赋值会改变记录的字段结构，给 `NR` 赋值通常只会让统计混乱，不建议。

### 用 -v 传入变量

```shell
$ awk -v n=3 'BEGIN { print n + 2 }'
5
```

`-v` 在 `BEGIN` 之前生效，适合传入阈值、文件名、格式等。`-v` 会处理反斜杠转义，例如 `-v sep='\t'` 会得到制表符。需要原样传递反斜杠时，注意转义层数。

变量也可以写在程序后面，作为“命令-line assignment”：

```shell
awk '{ print x, $1 }' x=hello examples/data/team-a.tsv
```

这种赋值在 awk 处理到对应文件参数时才生效，位置会影响结果。初学阶段优先用 `-v`，行为更直观。

### ENVIRON

`ENVIRON` 是 awk 预定义的关联数组，保存环境变量。数组语法在[关联数组](arrays.md)里讲，这里先看用法：

```shell
$ awk 'BEGIN { print ENVIRON["HOME"] }'
/c/Users/Administrator
```

输出取决于你的环境。`ENVIRON["HOME"]` 的值是字符串，可以直接拼接、比较或作为文件名。

### CONVFMT 与 OFMT

awk 在“数字转字符串”时使用 `CONVFMT`，在 `print` 输出数字时使用 `OFMT`。默认都接近 `%.6g`：

```shell
$ awk 'BEGIN { CONVFMT = "%.2f"; x = 1 / 3; print x "" }'
0.33

$ awk 'BEGIN { OFMT = "%.2f"; print 1 / 3 }'
0.33
```

- `x ""` 触发数字到字符串的转换，使用 `CONVFMT`。
- `print x` 直接输出数字，使用 `OFMT`。
- `printf` 使用自己的格式，不受这两个变量影响。

金额和报表建议用 `printf` 明确格式，不要依赖默认的 `OFMT`。

### 数值字面量

awk 支持整数、小数和科学计数法：

```shell
$ awk 'BEGIN { print 1e3; print 1e-3; print 1.5e2 }'
1000
0.001
150
```

以 `0` 开头的数字在 awk 里不是八进制（gawk 默认按十进制），但不同实现和 `--posix` 可能有差异。处理带前导零的编号（例如订单号 `00123`）时，把它当字符串，不要当数字，否则前导零会丢失。

### 常见陷阱

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| `if (x = 1)` 总是真 | 用了赋值 `=`，不是比较 `==` | 改成 `x == 1` |
| `"10" > 9` 为假 | 普通字符串和数字按字符串比较 | 用 `$1 + 0` 或确保是数字 |
| `010` 和 `10` 比较相等 | 输入字段是 `strnum`，按数值比较 | 需要保留文本时按字符串比较 |
| `print 1/3` 得到 `0.333333` | 默认 `OFMT` 只有 6 位有效数字 | 用 `printf "%.2f"` 或设置 `OFMT` |
| `$NF - 1` 不是倒数第二个字段 | 运算顺序是 `($NF) - 1` | 写 `$(NF - 1)` |
| `total += $4` 第一次结果不对 | `total` 未初始化或 `$4` 是表头字符串 | 在 `BEGIN` 初始化，并排除表头 |
| 浮点金额对不上 | 二进制浮点误差 | 用整数分计算，或统一 `printf` 输出 |
| 变量名拼错没有报错 | awk 把未定义变量当空/0 | 在 `BEGIN` 初始化，或用 `--lint` |

### 小结

- awk 有数字、字符串和 `strnum` 三种值；输入字段通常是 `strnum`。
- `/` 是浮点除法，整数除法用 `int()`；金额避免直接浮点比较。
- 相邻表达式是字符串拼接，`print a, b` 才用 `OFS`。
- 比较规则取决于操作数类型；不确定时用 `+0` 或 `""` 强制转换。
- `-v` 在 `BEGIN` 前设置变量，适合传参。
- `CONVFMT` 管数字转字符串，`OFMT` 管 `print` 数字，`printf` 不受影响。
- 未初始化变量是空字符串/0，显式初始化更可靠。

awk '

awk -F '\t' 'NR > 1 { printf "%s %.2f\n", $2, $4 * 0.8 }' examples/data/employees.tsv

```shell
awk 'BEGIN {
  print ("10" > 9)
  print (10 > 9)
  print ("10" > "9")
  print ("10" == 10)
  print ("10" == "10")
}'
```

`"10" > 9` 是字符串比较，为假；`10 > 9` 是数值比较，为真；`"10" > "9"` 是字符串比较，为假；`"10" == 10` 为真，因为数字 `10` 被转成字符串 `"10"` 后与 `"10"` 相等；`"10" == "10"` 为真。可以再验证 `"010" == 10` 为假：字符串比较下 `"010"` 不等于 `"10"`。

awk -v limit=100000 -F '\t' 'NR > 1 && $4 > limit { print $2, $4 }' examples/data/employees.tsv

```shell
awk 'BEGIN { print length(ENVIRON["HOME"]) }'
```

`print 1 2` 输出 `12`，因为相邻表达式是字符串拼接；`print 1, 2` 输出 `1 2`，因为逗号使用 `OFS`。
